## Assignment

Recreate a London-themed webpage based on the reference provided during the Boolean Tech Academy lesson. 

Create a new folder for today's exercise named: `html-london-trip`. Inside the `html-london-trip` folder, create a file named `index.html` (this will be the first page that opens on a website). 

Inside the `html-london-trip folder`, create a subfolder named `img` and place the necessary images there. The first 3 images (at the top) are included in the provided img.zip file, while the last two must be loaded using absolute paths.
